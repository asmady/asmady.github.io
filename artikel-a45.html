Cara Pakai ADB di Termux: Debug Android dari Terminal

11 Oktober 2026 · 7 menit baca

ADB (Android Debug Bridge) biasanya dipakai lewat komputer, tapi ternyata bisa juga dijalankan langsung dari Termux. Artikel ini jelaskan cara setup dan basic commands-nya.

Apa itu ADB?

ADB adalah tool command-line untuk komunikasi dengan Android device. Biasanya dipakai developer untuk debug, install app, dan akses terminal Android dari komputer. Ternyata, ADB client bisa jalan di Termux.

Install ADB di Termux

pkg update
pkg install android-tools

Setelah install, cek dengan:

adb version

Connect ADB ke Device Android Lain

Untuk connect ke HP lain, aktifkan Developer Options dan USB Debugging di HP target. Lalu:

adb connect IP_ADDRESS:5555

Contoh:

adb connect 192.168.1.100:5555

Basic ADB Commands yang Berguna

  • adb devices — Liat device yang terhubung
  • adb shell — Masuk terminal remote device
  • adb install app.apk — Install aplikasi remote
  • adb pull /path/file — Download file dari device
  • adb push file /path — Upload file ke device
  • adb logcat — Liat log real-time
  • adb reboot — Restart device remote

ADB Over WiFi (Tanpa Kabel)

  1. Connect HP target ke WiFi yang sama dengan Termux
  2. Di HP target: Settings - About Phone - tap Build Number 7x
  3. Developer Options - USB Debugging - Enable
  4. Wireless Debugging - Enable
  5. Di Termux: adb pair IP:PORT dengan pairing code
  6. Lalu adb connect IP:PORT

Use Cases ADB dari Termux

  • Debug app — Liat logcat dari HP lain
  • Backup — Pull file dari device remote
  • Install mod — Install APK tanpa transfer manual
  • Script automation — Buat script Termux yang kontrol HP lain
ADB di Termux membuka kemungkinan automation yang powerful. Satu HP bisa jadi remote control HP lainnya.

Mulai dari basic commands di atas, kamu bisa explore lebih jauh sesuai kebutuhan. Selamat mencoba!
