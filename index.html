Cron Job di Termux: Jadwal Otomatis Tugas di HP Android

Cron job di Termux bisa jalanin script otomatis sesuai jadwal yang kamu tentuin. Backup harian, download otomatis, kirim laporan — semua jalan sendiri tanpa kamu sentuh. Ini panduan lengkap setup cron di Termux dari nol.

Apa Itu Cron?

Cron adalah scheduler di Linux/Unix yang menjalankan perintah sesuai jadwal. Biasanya dipakai di server buat backup, update, maintenance. Tapi ternyata bisa juga jalan di Android pakai Termux.

Install Cron di Termux

pkg update && pkg install cronie

Setelah install, kamu perlu start cron daemon-nya:

cron

Perintah ini akan memulai cron service di background. Untuk berhenti, pakai cron -k.

Membuat Cron Job

Edit crontab dengan perintah:

crontab -e

Buka editor (biasanya nano atau vim), lalu tambahkan baris jadwal. Format cron:

* * * * *  perintah
| | | | |
| | | | +-- hari dalam minggu (0-7)
| | | +---- bulan (1-12)
| | +------ hari dalam bulan (1-31)
| +-------- jam (0-23)
+---------- menit (0-59)

Contoh Cron Job yang Berguna

  • Backup harian jam 3 pagi: 0 3 * * * rsync -av ~/data /sdcard/backup/
  • Download OTTO jam 8 pagi: 0 8 * * * wget -O ~/laporan https://contoh.com/api/laporan
  • Kirim notifikasi jam 9 pagi: 0 9 * * * termux-notification -t "Pengingat" -c "Jangan lupa minum air!"

Penting: Termux Harus Aktif

Cron job cuma jalan kalau Termux sedang aktif (kecil kemungkinan kalau HP di-reboot). Buat pastikan:

  • HP nggak mati (cron nggak jalan kalau mati)
  • Termux jangan di-force close

Kesimpulan

Contoh Nyata: Script Monitoring Baterai Otomatis

Buat file ~/battery_monitor.sh:

#!/data/data/com.termux/files/usr/bin/bash
# Kirim notifikasi kalau baterai < 20% dan nggak di-charge

while true; do
  status=$(termux-battery-status | jq -r '.percentage')
  charging=$(termux-battery-status | jq -r '.plugged')
  
  if [ "$status" -lt 20 ] && [ "$charging" != "AC" ] && [ "$charging" != "USB" ]; then
    termux-notification -t "Baterai Rendah" -c "Sisa ${status}%, segera charge!" --priority high
    termux-vibrate -d 1000
  fi
  
  sleep 300  # cek tiap 5 menit
done

Jalanin di background:

chmod +x ~/battery_monitor.sh
nohup ~/battery_monitor.sh > /dev/null 2>&1 &

Kenapa SSH dari HP Android?

Instalasi SSH di Termux

Pertama, update paket Termux:

pkg update && pkg upgrade

Lalu install OpenSSH:

pkg install openssh

ssh user@ip-server

Generate SSH Key

Alih-alih pakai password, lebih aman pakai SSH key. Generate key dengan:

ssh-keygen -t ed25519

ssh-copy-id user@ip-server

Sekarang kamu bisa login tanpa password.

Kalau kamu punya banyak server, buat file config di ~/.ssh/config:

Host myserver

  Port 22

Sekarang cukup ketik ssh myserver untuk connect.

Bash script adalah file teks yang berisi serangkaian perintah bash. Kamu bisa jalankan semua perintah itu sekaligus dengan satu perintah. Script biasa digunakan untuk otomasi, backup, dan administrasi sistem.

Buat file dengan ekstensi .sh:

nano hello.sh

Langkah 2: Tulis Shebang dan Perintah

Baris pertama script harus shebang:

./hello.sh

Contoh Script Berguna

DATE=$(date +%Y%m%d)

echo "Backup selesai: backup_$DATE.tar.gz"

Script ini backup folder important_files ke file tar.gz dengan tanggal.

2. Rename File Massal

#!/bin/bash

for f in *.txt; do

# Install package yang sering dipake
pkg update

Cara Pakai tmux di Termux: Multi-Tasking di Terminal

Kalau kamu sering pakai terminal, pasti pernah butuh buka beberapa sesi sekaligus. Atau mungkin kamu pernah kehilangan sesi karena terminal tertutup. Solusinya? tmux — terminal multiplexer yang bisa multi-tasking di satu jendela.

Apa Itu tmux?

tmux (terminal multiplexer) adalah tools yang memungkinkan kamu buka beberapa sesi terminal dalam satu jendela. Kamu bisa split window, berpindah antar sesi, dan bahkan detach tanpa kehilangan proses yang sedang berjalan.

Install tmux di Termux

Pertama, update package manager dan install tmux:

pkg update && pkg install tmux

Setelah install selesai, kamu bisa langsung mulai pakai tmux.

Perintah Dasar tmux

Mulai Sesi Baru

tmux new -s namasesi

Contoh: tmux new -s coding — membuat sesi bernama "coding".

Split Window

tmux memungkinkan kamu split window menjadi beberapa panel:

• Ctrl+b " — split horizontal
• Ctrl+b % — split vertical

Navigasi Antar Panel

Ctrl+b lalu panah — pindah ke panel yang diinginkan.

Detach Sesi

Ctrl+b d — detach dari sesi tanpa menutup. Proses tetap berjalan di background.

Reattach Sesi

tmux attach -t namasesi — kembali ke sesi yang sudah ada.

Daftar Sesi

tmux ls — lihat semua sesi tmux yang sedang berjalan.

Contoh Penggunaan

Scenario 1: Coding + Log

Split window jadi dua: satu buat coding, satu buat lihat log server. Tinggal Ctrl+b " dan kamu bisa monitoring sambil coding.

Scenario 2: SSH ke Server

Kalau kamu SSH ke server dan koneksi putus, sesi tmux tetap aman. Cukup reattach dan kamu bisa lanjut dari mana kamu berhenti.

Scenario 3: Multi-Tasking

Buka beberapa sesi untuk tugas berbeda: satu buat coding, satu buat testing, satu buat monitoring. Berpindah antar sesi dengan mudah.

Customisasi tmux

tmux bisa di-customize lewat file konfigurasi ~/.tmux.conf. Beberapa customisasi populer:

• Ganti prefix key dari Ctrl+b ke Ctrl+a
• Tambah status bar dengan info sistem
• Aktifkan mouse support buat scroll dan click

Tips dan Trik

• Gunakan Ctrl+b z untuk zoom ke satu panel
• Ctrl+b c buat window baru
• Ctrl+b n pindah ke window berikutnya
• Ctrl+b p pindah ke window sebelumnya

Kesimpulan

tmux adalah tools wajib buat yang sering pakai terminal. Dengan tmux, kamu bisa multi-tasking dengan efisien, tidak kehilangan sesi, dan bekerja lebih produktif. Install sekali, pakai selamanya.

Perintah Dasar Curl

1. GET Request — Ambil Data

Buat ambil data dari API atau website:

curl https://api.example.com/data

Output akan muncul di terminal. Tambahkan -i buat lihat header response juga.

2. POST Request — Kirim Data

Buat submit form atau kirim data ke API:

curl -X POST https://api.example.com/login \
  -H "Content-Type: application/json" \
  -d '{"username":"asmady","password":"rahasia"}'

-X POST set method, -H tambah header, -d kirim data body.

3. Download File

Download file langsung dari terminal:

curl -O https://example.com/file.zip

-O simpan dengan nama asli file. Atau pakai -o namafile.zip buat nama custom.

4. Follow Redirect

Kalau URL redirect ke tempat lain, tambahkan -L:

curl -L https://short.url/abc

curl akan ikuti redirect sampai dapat tujuan akhir.

5. Save Output ke File

Alih-alih tampil di terminal, simpan langsung ke file:

curl https://api.example.com/data.json -o data.json

Berguna buat nyimpen response API buat diproses lagi.

Tips dan Trik

  • -s mode silent — nggak tampil progress bar
  • -v verbose — lihat detail request/response, berguna buat debug
  • -k skip SSL verification — hati-hati, cuma buat testing
  • --max-time 30 set timeout 30 detik

Kesalahan Umum

Paling sering: lupa escape karakter khusus di JSON. Kalau dapat error "unexpected character", cek lagi JSON body-nya. Kedua: lupa tambah header Content-Type saat POST data. Banyak API yang reject kalau header ini nggak ada.

Kesimpulan

curl adalah tools yang wajib dikuasai siapa aja yang berhubungan dengan API atau otomasi. Di Termux, kamu bisa testing API, download file, dan bikin script otomasi langsung dari HP. Mulai dari perintah dasar, terus explore — curl itu dalam dan powerful.

Cara Pakai jq di Termux: Parsing JSON dari Terminal

14 Oktober 2026 · 6 menit baca

Kalau kamu pernah kerja dengan API atau data JSON di terminal, kamu tahu rasanya: JSON itu susah dibaca mentah. Banyak kurung, tanda koma, dan indentasi berantakan. Nah, ada tool yang bikin hidup lebih mudah: jq. Ini parser JSON command-line yang powerful, dan bisa jalan di Termux.

Apa itu jq?

jq itu tool buat memanipulasi JSON dari terminal. Bisa filter, extract, transform, dan format JSON dengan satu perintah. Bayangin grep atau awk, tapi khusus buat JSON. Ringkasnya: kalau kamu kerja dengan API, jq itu wajib punya.

Install jq di Termux

Gampang banget, satu perintah:

pkg install jq

Selesai. Cek versi:

jq --version

Kalau muncul versi (biasanya 1.6 atau 1.7), berarti siap dipakai.

Dasar-dasar jq

1. Pretty Print JSON

Fungsi paling dasar: baca JSON jadi rapi:

echo '{"nama":"Budi","umur":25}' | jq .

Outputnya:

{
  "nama": "Budi",
  "umur": 25
}

2. Extract Nilai Spesifik

Mau ambil nilai tertentu aja:

echo '{"nama":"Budi","umur":25}' | jq '.nama'

Output: "Budi"

3. Filter Array

JSON sering berisi array. Contoh:

echo '[{"nama":"Budi"},{"nama":"Siti"}]' | jq '.[].nama'

Output:

"Budi"
"Siti"

4. Filter dengan Kondisi

Mau ambil data yang umurnya di atas 20:

echo '[{"nama":"Budi","umur":25},{"nama":"Ani","umur":18}]' | jq '.[] | select(.umur > 20)'

5. Hitung Jumlah Data

echo '[1,2,3,4,5]' | jq 'length'

Output: 5

6. Sort dan Unik

echo '[3,1,2,1]' | jq 'sort | unique'

Output: [1,2,3]

7. Buat JSON Baru

echo '{}' | jq '.nama = "Budi" | .umur = 25'

Output: {"nama":"Budi","umur":25}

Praktis: Pakai jq dengan API

Contoh nyata: ambil data dari API publik:

curl -s "https://api.github.com/users/torvalds" | jq '.name, .public_repos'

Atau simpan ke file dulu:

curl -s "https://api.github.com/users/torvalds" | jq '.name' > nama.txt

Tips Penting

  • Selalu pakai -s (silent) dengan curl biar progress bar nggak ngotori output
  • Simpan output jq ke file kalau mau diproses lagi
  • Pakai -r (raw output) kalau mau hasil tanpa tanda kutip: jq -r '.nama'
  • Bisa digabung dengan grep, awk, atau sed untuk processing lanjutan

Kesimpulan

jq itu tool kecil yang dampaknya besar. Sekali kamu bisa pakai jq, kamu nggak akan mau balik ke parsing JSON manual lagi. Install sekali, pakai selamanya.

1. Bing Image Creator (DALL-E 3 Gratis)

Bing Image Creator adalah cara paling mudah akses DALL-E 3 gratis. Cukup punya akun Microsoft (bisa daftar gratis), buka bing.com/images/create, ketik prompt dalam bahasa Indonesia atau Inggris, tekan Enter. Dalam 10-30 detik dapat 4 variasi gambar.

Kelebihan: kualitas tinggi, paham prompt bahasa Indonesia, gratis unlimited (hanya butuh "boost" yang isi ulang tiap hari). Kekurangan: butuh login, kadang lambat saat ramai, filter ketat (nggak bisa generate orang terkenal, brand, atau kontak sensitif).

Cocok buat: asset game, karakter konsisten, konsep desain, ilustrasi detail. Fitur keren: Canvas Editor buat inpainting/outpainting (edit bagian gambar), ControlNet buat kontrol pose/komposisi.

Catatan: UI agak kompleks buat pemula, kredit habis cepat kalau generate resolusi tinggi.

3. Ideogram (Gratis 25 Prompt/Hari)

Ideogram unggul di satu hal: teks di dalam gambar. Kalau butuh gambar dengan tulisan (misal logo, poster, meme, thumbnail dengan judul), Ideogram paling akurat dibanding yang lain. Versi gratis dapat 25 prompt per hari (100 gambar).

Kelebihan: render teks paling bagus, style preset lengkap (Typography, Poster, 3D Render, dll), komunitas aktif buat lihat prompt orang lain. Kekurangan: limit harian ketat, kadang lambat.

Kalau punya GPU (minimal 8GB VRAM) atau mau jalanin di cloud gratis (Google Colab, Hugging Face Spaces), tools open source ini gratis selamanya tanpa limit:

  • ComfyUI — node-based, lebih cepat dan fleksibel, kurva belajar lebih curam tapi powerful banget buat pipeline kompleks.
  • Fooocus — UI simpel mirip Midjourney, "install and forget", kualitas bagus out-of-the-box.

import subprocess
import shutil

def cek_storage():
    total, used, free = shutil.disk_usage("/data/data/com.termux/files/home")
    print(f"=== Storage Termux ===")
    print(f"Total: {total // (1024**3)} GB")
    print(f"Terpakai: {used // (1024**3)} GB")
    print(f"Sisa: {free // (1024**3)} GB")
    
    # Cek storage HP umum
    hasil = subprocess.run(['df', '-h', '/sdcard'], capture_output=True, text=True)
    print(f"\n=== Storage Internal ===")

if __name__ == "__main__":

Script Monitoring Website/Uptime

Script monitor.py cek website tiap 5 menit:

import requests
import time
import subprocess
from datetime import datetime

def cek_url(url, nama):
    try:
        r = requests.get(url, timeout=10)
        status = "UP" if r.status_code == 200 else f"DOWN ({r.status_code})"
    except Exception as e:
        status = f"ERROR: {e}"
    
    waktu = datetime.now().strftime("%H:%M:%S")
    pesan = f"[{waktu}] {nama}: {status}"
    print(pesan)
    
    # Notif kalau down
    if "DOWN" in status or "ERROR" in status:
        subprocess.run(["termux-notification", "--title", "Monitoring", "--content", pesan, "--priority", "high"])

if __name__ == "__main__":
    targets = [
        ("https://google.com", "Google"),
        ("https://github.com", "GitHub"),
        # tambah URL lain di sini
    ]
    
    print("Monitoring dimulai... (Ctrl+C buat berhenti)")
    while True:
        for url, nama in targets:
            cek_url(url, nama)
        time.sleep(300)  # 5 menit

Niche Blog — Cara Memilih Topik yang Menghasilkan

Banyak blogger pemula yang bingung kenapa kontennya jarang dikunjungi. Padahal sudah rajin nulis, tapi trafik tetap sepi. Seringkali masalahnya bukan di kualitas tulisan, tapi di pemilihan niche. Niche adalah topik spesifik yang jadi fokus utama blog kamu. Daripada nulis tentang "teknologi" yang terlalu luas, kamu bisa fokus ke "review laptop gaming di bawah 10 juta". Itu dia niche.

Kenapa Niche Itu Penting?

Blog yang punya niche jelas lebih mudah dikenali mesin pencari dan pembaca. Google suka situs yang punya otoritas di satu topik tertentu. Toko spesifik lebih mudah diingat dan dipercaya.

Cara Riset Niche yang Menguntungkan

Sebelum commit ke satu niche, lakukan riset dulu. Ini langkah-langkahnya:

  • Google Trends: Cek apakah minat terhadap topik kamu naik atau turun dari waktu ke waktu. Pilih niche dengan tren stabil atau meningkat.
  • Google Keyword Planner: Lihat volume pencarian dan tingkat kompetisi keyword. Idealnya, volume tinggi dengan kompetisi rendah.
  • Analisis Kompetisi: Lihat blog-blog yang sudah sukses di niche yang sama. Baca konten mereka, cari celah yang belum terisi.
  • Forum dan Komunitas: Cek Reddit, Kaskus, atau Facebook Group. Pertanyaan yang sering muncul itu peluang konten.

Tips: Jangan pilih niche yang kamu sendiri tidak suka. Riset itu penting, tapi kalau kamu tidak menikmatinya, kamu akan cepat bosan dan berhenti di tengah jalan.

GitHub Pages — Hosting Blog Gratis dengan Custom Domain

Apa Itu GitHub Pages?

GitHub Pages adalah fitur hosting statis gratis dari GitHub. Kamu bisa nampilin blog, portfolio, atau dokumentasi langsung dari repo GitHub tanpa perlu bayar hosting. Cukup push file HTML, CSS, dan JS, lalu GitHub yang urus sisanya. Buat yang mau punya blog pribadi tapi nggak mau ribet, ini solusi paling simpel dan cepat.

Setup Repository

Pertama, bikin repo baru di GitHub. Kalau mau blog di root domain seperti username.github.io, namai repo kamu username.github.io. Kalau cuma mau subdomain atau path tertentu, nama repo bebas. Terus clone ke komputer lokal:

git clone https://github.com/username/repo-blog.git
cd repo-blog

Pilih Theme Jekyll atau Upload Static HTML

Dua opsi utama: pakai Jekyll theme atau upload static HTML langsung. Kalau pakai Jekyll, kamu bisa pilih theme dari Settings, lalu Pages, lalu Choose a theme. GitHub otomatis generate situsnya. Kalau mau kontrol penuh, cukup upload file index.html beserta CSS dan JS kamu. Jekyll cocok buat blog dengan banyak artikel, static HTML cocok buat landing page atau portfolio.

Aktifkan Pages di Settings

Setelah push file, masuk ke repo di GitHub, klik Settings, lalu Pages. Di bagian Source, pilih branch main dan folder / (root). Klik Save. Dalam beberapa menit, blog kamu live di https://username.github.io/repo-blog/.

Custom Domain dengan CNAME

Mau pakai domain sendiri? Beli domain di Namecheap, Cloudflare, atau registrar lain. Di repo, buat file bernama CNAME tanpa ekstensi, berisi domain kamu:

www.domainkamu.com

Lalu di DNS provider, tambah record CNAME yang mengarah ke username.github.io. Di Settings, Pages, isi kolom Custom domain dengan domain kamu. Tunggu DNS propagate, biasanya beberapa menit sampai beberapa jam.

HTTPS Otomatis

GitHub Pages otomatis kasih sertifikat HTTPS gratis via Let's Encrypt. Setelah custom domain terverifikasi, centang Enforce HTTPS di Settings, lalu Pages. Pengunjung blog kamu aman dan nggak muncul peringatan Not Secure.

Batasan yang Perlu Diketahui

GitHub Pages gratis, tapi ada batasannya:

  • Bandwidth: 100 GB per bulan
  • Storage: 1 GB per repo
  • Build: 10 build per jam
  • Ukuran file: maksimal 100 MB per file

Untuk blog personal, batasan ini lebih dari cukup. Kalau traffic sudah besar, mungkin saatnya pindah ke Vercel atau Netlify.

Tips Tambahan

Gunakan Jekyll dengan theme minimalis supaya loading cepat dan SEO-friendly. Jangan lupa tambahkan meta description di setiap artikel.

Backup repo secara berkala. Meskipun GitHub reliable, tetap baik punya salinan lokal atau remote lain.

Manfaatkan GitHub Actions untuk auto-deploy kalau pakai static site generator seperti Hugo atau Astro.

GitHub Pages adalah cara paling murah dan cepat untuk punya blog online. Dengan custom domain, blog kamu terlihat profesional tanpa keluar uang sepeser pun. Selamat mencoba!

Cara Pakai ADB di Termux: Debug Android dari Terminal

Apa itu ADB?

ADB adalah tool command-line untuk komunikasi dengan Android device. Biasanya dipakai developer untuk debug, install app, dan akses terminal Android dari komputer. Ternyata, ADB client bisa jalan di Termux.

Install ADB di Termux

pkg update
pkg install android-tools

Setelah install, cek dengan:

adb version

Connect ADB ke Device Android Lain

Untuk connect ke HP lain, aktifkan Developer Options dan USB Debugging di HP target. Lalu:

adb connect IP_ADDRESS:5555

Contoh:

adb connect 192.168.1.100:5555

Basic ADB Commands yang Berguna

  • adb devices — Liat device yang terhubung
  • adb shell — Masuk terminal remote device
  • adb install app.apk — Install aplikasi remote
  • adb pull /path/file — Download file dari device
  • adb push file /path — Upload file ke device
  • adb logcat — Liat log real-time
  • adb reboot — Restart device remote

ADB Over WiFi (Tanpa Kabel)

  1. Connect HP target ke WiFi yang sama dengan Termux
  2. Di HP target: Settings - About Phone - tap Build Number 7x
  3. Developer Options - USB Debugging - Enable
  4. Wireless Debugging - Enable
  5. Di Termux: adb pair IP:PORT dengan pairing code
  6. Lalu adb connect IP:PORT

Use Cases ADB dari Termux

  • Debug app — Liat logcat dari HP lain
  • Backup — Pull file dari device remote
  • Install mod — Install APK tanpa transfer manual
  • Script automation — Buat script Termux yang kontrol HP lain
ADB di Termux membuka kemungkinan automation yang powerful. Satu HP bisa jadi remote control HP lainnya.

Cara Pakai rsync di Termux: Backup File ke Server

11 Oktober 2026 · 7 menit baca

Punya file penting di HP — foto, project coding, config bot — tapi takut hilang kalau HP rusak atau kehilangan? rsync adalah solusi backup paling efisien: cuma transfer file yang berubah, support SSH, dan bisa di-jadwalkan otomatis via cron. Cocok banget buat backup ke VPS atau server rumah.

Kenapa rsync Bukan cp atau scp?

  • Incremental — Hanya file yang berubah (size, timestamp, permission) yang dikirim. Backup 10 GB jadi detik kalau cuma 50 MB berubah
  • Resume — Koneksi putus? Lanjut dari mana berhenti, nggak mulai dari nol
  • Compression -z compress data saat transfer, hemat bandwidth
  • SSH native — Pakai key authentication, aman dan passwordless

Install rsync di Termux

pkg update && pkg install rsync openssh

rsync biasanya sudah ada di package default. openssh dibutuhkan untuk SSH connection ke server.

Setup SSH Key ke Server

Biar backup otomatis tanpa password:

ssh-keygen -t ed25519
ssh-copy-id user@ip-server-kamu

Test koneksi: ssh user@ip-server harus bisa login tanpa password.

Command rsync Dasar

# Backup folder ke server
rsync -avz ~/folder-penting user@ip-server:/path/backup/

# Opsi penjelasan:
# -a = archive (preserve permission, timestamp, symlink)
# -v = verbose (tampilin progress)
# -z = compress (kompres saat transfer)
# --delete = hapus di destination kalau dihapus di source (hati-hati!)

Contoh Praktis: Backup Project Coding

Buat script backup di ~/backup-project.sh:

#!/bin/bash
# Backup project ke VPS
rsync -avz --exclude='node_modules' --exclude='.git' \
  ~/project-coding/ user@ip-server:/home/user/backup/project-coding/ \
  >> ~/backup.log 2>&1

--exclude skip folder yang nggak perlu dibackup (node_modules, .git, __pycache__). Log disimpan ke ~/backup.log buat monitoring.

Otomatisasi dengan Cron

chmod +x ~/backup-project.sh
crontab -e
# Tambah baris: backup tiap jam 2 pagi
0 2 * * * ~/backup-project.sh

Sekarang tiap jam 2 pagi, project kamu otomatis ter-backup ke server. Cek log: tail ~/backup.log.

Restore dari Backup

# Ambil backup dari server ke HP
rsync -avz user@ip-server:/home/user/backup/project-coding/ ~/project-coding-restore/

Tips Tambahan

  • Dry run dulu — Tambah -n atau --dry-run buat lihat apa yang akan di-transfer tanpa benar-benar transfer
  • Bandwidth limit — --bwlimit=1000 batasi 1 MB/s biar nggak makan bandwidth penuh
  • Multiple destination — Bisa backup ke 2 server beda lokasi buat redundancy
rsync + cron = backup otomatis yang set-and-forget. Setup sekali, damai selamanya.

Dengan rsync di Termux, HP Android kamu jadi client backup yang powerful. File penting aman di server, kamu tidur nyenyak. Selamat mencoba!

Cara Pakai Screen di Termux: Alternatif Tmux

10 Oktober 2026 · 6 menit baca

Kalau kamu sering ngoding di HP pakai Termux, pasti udah nggak asing sama Tmux. Tapi ternyata ada alternatif lain yang lebih ringan dan gampang dipakai: GNU Screen. Artikel ini bakal ngajarin kamu cara pakai Screen di Termux dari nol, biar sesi terminal kamu nggak hilang pas layar mati atau koneksi putus.

Apa Itu Screen dan Bedanya Sama Tmux?

GNU Screen itu program terminal multiplexer — intinya, kamu bisa bikin banyak "jendela" dalam satu terminal, dan sesi kamu tetap jalan di background walau kamu nutup aplikasi. Bedanya sama Tmux? Screen lebih simpel, perintahnya lebih sedikit, dan kebanyakan orang merasa lebih cepat belajar Screen daripada Tmux. Tmux lebih powerful, tapi kalau kamu cuma butuh fitur dasar, Screen cukup.

Install Screen di Termux

Pertama, update dulu paket Termux kamu, terus install Screen:

pkg update && pkg upgrade
pkg install screen

Selesai! Sekarang kamu bisa langsung pakai perintah screen di terminal.

Basic Commands: New Session, Detach, Attach

Ini tiga perintah paling penting yang harus kamu hafalin:

  • Bikin sesi baru: screen -S namasesi — ganti "namasesi" dengan nama yang kamu suka, misalnya screen -S belajar.
  • Detach (sembunyikan sesi): Tekan Ctrl+A lalu D. Sesi kamu tetap jalan di background.
  • Attach (kembali ke sesi): screen -r namasesi — atau cukup screen -r kalau cuma ada satu sesi.

Contoh praktis: kamu lagi jalanin script Python panjang, terus baterai HP mau habis. Tinggal detach, nutup Termux, charge dulu, terus attach lagi. Script kamu masih jalan!

Split Screen dan Scroll Mode

Screen juga bisa bagi layar jadi beberapa bagian. Caranya:

  • Split horizontal: Ctrl+A lalu S (huruf besar).
  • Pindah antar split: Ctrl+A lalu Tab.
  • Tutup split aktif: Ctrl+A lalu X.

Buat scroll ke atas lihat output lama, pakai Ctrl+A lalu [. Tekan Esc buat keluar dari scroll mode.

Tips dan Troubleshooting

Kalau screen -r bilang "There is no screen to resume", coba screen -ls buat lihat daftar sesi yang ada.

Beberapa tips biar makin lancar:

  1. Beri nama sesi yang jelas biar gampang diingat pas attach.
  2. Kalau sesi nggak bisa di-attach karena "attached" di tempat lain, pakai screen -d -r namasesi buat force detach dulu.
  3. Buat lihat semua sesi aktif: screen -ls.
  4. Kalau mau sesi langsung mati pas ditutup, pastikan kamu tekan Ctrl+A lalu K (kill) buatakhiri sesi.

Itu dia dasar-dasar pakai Screen di Termux. Gampang kan? Sekarang kamu bisa kerja lebih fleksibel di HP tanpa takut sesi hilang. Selamat mencoba!

Cara Pakai FFmpeg di Termux: Edit Video dan Audio dari Terminal

10 Oktober 2026 · 7 menit baca

FFmpeg adalah tools multimedia paling powerful di dunia Linux. Dengan FFmpeg, kamu bisa convert, compress, edit, dan memanipulasi video dan audio langsung dari terminal. Artikel ini bantu kamu install dan mulai pakai FFmpeg di Termux.

Apa itu FFmpeg?

FFmpeg adalah command-line tool untuk memproses file multimedia. Bisa convert format, compress video, extract audio, merge file, dan masih banyak lagi. Ini tools yang dipakai banyak profesional video editing, tapi bisa dipakai siapa saja.

Install FFmpeg di Termux

pkg update && pkg install ffmpeg -y

Tunggu sampai selesai. Cek versi dengan:

ffmpeg -version

Perintah Dasar FFmpeg

1. Convert Format Video

ffmpeg -i input.mp4 output.avi

Ganti input.mp4 dengan file video kamu, dan output.avi dengan format tujuan.

2. Compress Video

ffmpeg -i input.mp4 -vcodec libx264 -crf 28 output.mp4

Parameter -crf 28 mengatur kualitas. Angka lebih kecil = kualitas lebih besar, ukuran lebih besar. Range 18-28 masih acceptable.

3. Extract Audio dari Video

ffmpeg -i input.mp4 -vn -acodec libmp3lame output.mp3

Ini akan extract audio dari video dan simpan sebagai MP3.

4. Merge Video dan Audio

ffmpeg -i video.mp4 -i audio.mp3 -c:v copy -c:a aac output.mp4

Gabungkan file video dan audio menjadi satu file MP4.

5. Potong Video

ffmpeg -i input.mp4 -ss 00:00:30 -t 00:00:10 -c copy output.mp4

-ss untuk start time, -t untuk durasi. Contoh di atas potong video dari detik 30 selama 10 detik.

6. Convert Audio Format

ffmpeg -i input.wav output.mp3

Convert audio dari WAV ke MP3 atau format lain.

Contoh Penggunaan Praktis

Compress Video untuk WhatsApp

WhatsApp punya batasan ukuran file. Compress video dengan:

ffmpeg -i video-asli.mp4 -vcodec libx264 -crf 30 -preset fast video-wa.mp4

Buat GIF dari Video

ffmpeg -i input.mp4 -vf "fps=10,scale=320:-1" output.gif

Buat GIF dari video dengan fps 10 dan lebar 320px.

Ringkas Audio Podcast

ffmpeg -i podcast.mp3 -af "volume=1.5" podcast-loud.mp3

Naikkan volume audio podcast yang terlalu pelan.

Tips Penting

  • Selalu backup file original sebelum proses FFmpeg
  • Cek format yang didukung dengan ffmpeg -formats
  • Gunakan -preset fast untuk proses lebih cepat
  • Log error — kalau gagal, baca pesan error di terminal

Troubleshooting

Error: "command not found" — Pastikan FFmpeg sudah terinstall dengan benar.

Error: "Permission denied" — Berikan akses storage ke Termux dengan termux-setup-storage.

Proses lambat — Normal untuk video besar. Gunakan -preset fast untuk mempercepat.

FFmpeg adalah pisau Swiss Army untuk multimedia. Kuasai dasar-dasarnya, dan kamu bisa edit video/audio tanpa aplikasi mahal.

Dengan FFmpeg di Termux, HP Android kamu bisa jadi tools editing video yang powerful. Mulai dari perintah dasar, tambah kompleksitas bertahap.

Cara Pakai GitHub Actions untuk Otomasi Blog

10 Oktober 2026 · 7 menit baca

Setiap kali nambah artikel baru, kamu harus commit, push, dan tunggu GitHub Pages update. Kalau sering posting, proses ini bisa membosankan. Dengan GitHub Actions, semua proses ini bisa diotomatisasi. Artikel ini bantu kamu setup CI/CD untuk blog GitHub Pages dari nol.

Apa itu GitHub Actions?

GitHub Actions adalah tool CI/CD (Continuous Integration/Continuous Deployment) bawaan GitHub. Dengan Actions, kamu bisa menjalankan workflow otomatis setiap kali ada perubahan di repository. Misalnya: setiap kali push ke main, otomatis build dan deploy ke GitHub Pages.

Struktur File Workflow

File workflow disimpan di folder .github/workflows/ di root repository. File berformat YAML. Berikut contoh workflow sederhana untuk deploy ke GitHub Pages:

name: Deploy to GitHub Pages

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./

Langkah Setup

  1. Buka repository blog kamu di GitHub
  2. Klik tab Settings
  3. Di sidebar kiri, klik Pages
  4. Bagian Source, pilih GitHub Actions (bukan Deploy from branch)
  5. Commit dan push file workflow di atas ke repository
  6. Setiap kali kamu push artikel baru, workflow akan otomatis jalan dan deploy

Keuntungan Otomasi

  • Tidak perlu deploy manual — Push artikel, selesai
  • Build otomatis — Kalau ada error, kamu dapat notifikasi
  • Gratis — GitHub Actions gratis untuk public repository
  • Rollback mudah — Kalau ada masalah, tinggal revert commit

Troubleshooting

Kalau workflow gagal, cek tab Actions di repository. Kamu bisa lihat log lengkap dan tahu di step mana error terjadi. Biasanya masalah umum adalah permission token atau path publish_dir yang salah.

Otomasi bukan untuk membuat kamu malas, tapi untuk fokus ke konten daripada proses teknis.

Dengan GitHub Actions, setiap artikel yang kamu push akan otomatis live tanpa perlu deploy manual. Lebih cepat, lebih efisien. Selamat mencoba!

Cara Pakai Runit di Termux: Auto-restart Service

9 Oktober 2026 · 6 menit baca

Pernah bikin bot atau script di Termux, tapi kalau HP restart semua berhenti? Runit adalah service manager lightweight yang bisa auto-restart aplikasi saat HP dinyalakan ulang. Artikel ini bantu kamu setup runit dari nol.

Apa itu Runit?

Runit adalah init system dan service manager untuk Unix-like systems. Di Termux, runit berguna untuk menjaga script, bot, atau server tetap jalan otomatis. Kalau process mati karena alasan apa pun, runit akan restart secara otomatis.

Install Runit di Termux

pkg update && pkg install runit -y

Setelah install, runit siap dikonfigurasi. Tidak perlu setup tambahan untuk penggunaan dasar.

Membuat Service Baru

  1. Buat folder service:
mkdir -p ~/service/bot-ku
  1. Buat file run:
nano ~/service/bot-ku/run
  1. Isi dengan script yang mau dijalankan:
#!/bin/bash
cd ~/bot-ku
while true; do
  python3 bot.py
  sleep 5
done
  1. Berikan izin eksekusi:
chmod +x ~/service/bot-ku/run

Menjalankan Service

Untuk menjalankan service dengan runit:

runsv ~/service/bot-ku &

Service akan berjalan di background. Kalau process di dalamnya mati, runsv akan otomatis restart sesuai interval yang ditentukan.

Auto-start saat HP Boot

Biar service jalan otomatis saat HP dinyalakan, tambahkan ke boot script. Edit file ~/.termux/boot/start-runit.sh:

#!/bin/bash
# Tunggu Termux siap
sleep 10

# Jalankan semua service
for svc in ~/service/*/; do
  if [ -f "$svc/run" ]; then
    runsv "$svc" &
  fi
done

Berikan izin eksekusi: chmod +x ~/.termux/boot/start-runit.sh

Menghentikan Service

Untuk menghentikan service:

svc -d ~/service/bot-ku

Untuk menghapus service, hentikan dulu lalu hapus folder:

svc -d ~/service/bot-ku
rm -rf ~/service/bot-ku

Tips Penting

  • Log — Selalu simpan log service ke file untuk debugging
  • Resource — Jangan jalankan terlalu banyak service, hemat RAM dan baterai
  • Testing — Jalankan manual dulu sebelum ke runit untuk memastikan tidak ada error
Runit adalah cara paling sederhana dan reliable untuk menjaga script tetap hidup di HP Android tanpa root.

Dengan runit, bot atau automation kamu tidak akan mati lagi saat HP restart. Setup sekali, selamanya tenang.

Automasi dengan Python di Termux: Dari Script ke Scheduler

8 Oktober 2026 · 6 menit baca

Sudah install Python di Termux tapi belum tahapakenya untuk otomasi? Artikel ini bantu kamu bikin script sederhana yang bisa dijalankan otomatis tiap hari.

Script Sederhana untuk Cek Storage

#!/usr/bin/env python3
import os

def cek_storage():
    total = os.statvfs('.').f_blocks * os.statvfs('.').f_frsize
    free = os.statvfs('.').f_bfree * os.statvfs('.').f_frsize
    used = total - free
    print(f"Total: {total / 1024 / 1024:.1f} MB")
    print(f"Free: {free / 1024 / 1024:.1f} MB")
    print(f"Used: {used / 1024 / 1024:.1f} MB")

if __name__ == "__main__":
    cek_storage()

Script ini cuma amati ukuran storage di home directory. Kamu bisa modifikasi untuk ngecek file mana yang besar, atau bahkan ngering notifikasi kalau storage hampir penuh.

Menyimpan Script ke File

  1. Buka Termux dan ketik nano otomatisasi.py
  2. Copy script di atas ke dalam editor
  3. Simpan dengan Ctrl+O, Enter, lalu Ctrl+X
  4. Jalankan dengan python otomatisasi.py

Keluaran akan tampil di terminal berisi ukuran storage dalam MB.

Menjadwalkan dengan Cron

  1. Buat script backup di ~/otomatisasi.sh:
#!/bin/bash
cd ~
python otomatisasi.py > /storage/emulated/0/otomatisasi_log.txt 2>&1
  1. Berikan izin eksekusi:
chmod +x ~/otomatisasi.sh
  1. Tambah ke cron tiap pagi jam 8:
crontab -e
0 8 * * * ~/otomatisasi.sh

Dengan begitu, tiap pagi jam 8, script Python akan jalan dan log akan disimpan di storage HP.

Python di Termux Bisa jadi alat otomatisasi yang kuat, dari cek sederhana sampai script yang kompleks.

Cara Pakai SSH di Termux

8 Oktober 2026 · 7 menit baca

Pernah ngerasa harus bawa laptop terus cuma buat connect ke server? Atau mau manage server tapi lagi di jalan? Dengan SSH di Termux, kamu bisa connect ke server mana saja langsung dari HP Android.

Apa itu SSH?

SSH (Secure Shell) adalah protocol untuk connect ke server secara aman. Semua data terenkripsi, jadi aman dipakai di jaringan public. SSH biasa dipakai untuk manage server, transfer file, dan remote command.

Install SSH Client

Termux sudah include SSH client secara default. Cek dengan:

ssh -V

Kalau belum ada, install dengan:

pkg install openssh

Connect ke Server

Format dasar SSH:

ssh username@ip_address

Contoh:

ssh root@192.168.1.100

Kalau port custom:

ssh -p 2222 root@192.168.1.100

SSH Key untuk Login Tanpa Password

Biar tidak perlu ketik password setiap login, setup SSH key:

ssh-keygen -t ed25519
ssh-copy-id root@192.168.1.100

Setelah ini, login langsung tanpa password.

Transfer File dengan SCP

SSH juga bisa dipakai transfer file:

# Upload file ke server
scp file.txt root@192.168.1.100:/root/

# Download file dari server
scp root@192.168.1.100:/root/file.txt ./

SSH Config File

Biar tidak perlu ketik panjang setiap kali, buat config file:

nano ~/.ssh/config

Isi dengan:

Host myserver
    HostName 192.168.1.100
    User root
    Port 22
    IdentityFile ~/.ssh/id_ed25519

Sekarang cukup ketik ssh myserver untuk connect.

SSH Tunnel

SSH tunnel bisa dipakai untuk mengakses service di server secara aman:

# Local tunnel - akses service di server dari HP
ssh -L 8080:localhost:80 root@192.168.1.100

Sekarang buka localhost:8080 di browser HP untuk akses web server di remote.

SSH Agent

SSH agent menyimpan key di memory sehingga tidak perlu ketik passphrase setiap kali:

eval $(ssh-agent)
ssh-add ~/.ssh/id_ed25519

Sekarang key sudah di-load dan bisa dipakai berulang kali tanpa passphrase.

Troubleshooting Error Umum

  • Connection refused — Server tidak jalan atau port salah
  • Permission denied — Username/password salah atau SSH key tidak cocok
  • Host key verification failed — Server ganti key, hapus dengan ssh-keygen -R ip_address
  • Connection timed out — Firewall memblokir atau IP salah

Tips Keamanan

  • Disable root login — Buat user biasa, login sebagai user lalu sudo
  • Change default port — Port 22 sering di-scan bot
  • Gunakan SSH key — Lebih aman dari password
  • Fail2ban — Block IP yang terlalu banyak gagal login
SSH adalah jendela ke server mana saja. Dengan Termux, server ada di saku kamu.

Sekarang kamu bisa manage server dari mana saja tanpa bawa laptop. Selamat mencoba!

Cara Install dan Pakai Tmux di Termux

7 Oktober 2026 · 6 menit baca

Pernah ngerasa kesel karena HP Android kamu mati atau aplikasi ke-close, terus semua proses yang lalan tiba-tiba berhenti semua? Nah, di sinilah tmux jadi penyelamat. Tmux itu semacam terminal multiplexer, jadi kamu bisa bikin banyak "jendela" dalam satu terminal, dan yang paling penting: prosesnya tetap jalan walau kamu keluar dari Termux. Gampangnya, tmux bikin terminal kamu jadi lebih kuat dan tidak gampang mati.

Apa Itu Tmux?

Singkatnya, tmux (terminal multiplexer) itu alat yang memungkinkan kamu membuat, mengelola, dan berpindah antara beberapa sesi terminal dalam satu layar. Bayangkan kamu lagi ngerun script panjang, terus kamu mau buka aplikasi lain atau lock HP. Tanpa tmux, script-nya bakal berhenti. Dengan tmux, script tetap jalan di background. Ini sangat berguna buat kamu yang suka otomasi di Android, misalnya ngerun bot, cron job, atau server sederhana.

Cara Install Tmux di Termux

Install-nya gampang banget. Buka Termux, terus ketik perintah ini:

pkg update && pkg install tmux -y

Tunggu sampai selesai. Kalau sudah, coba cek versinya dengan:

tmux -V

Kalo muncul versi (misalnya tmux 3.x), berarti tmux sudah siap dipakai.

Membuat Session Baru

Session itu seperti "ruang kerja" di tmux. Kamu bisa bikin banyak session untuk beda-beda tujuan. Cara bikin session baru:

tmux new -s belajar

Di sini "belajar" adalah nama session-nya. Kamu bisa ganti terserah, misalnya bot, server, atau backup. Setelah perintah ini dijalankan, kamu bakal masuk ke session tmux. Perhatikan ada bar hijau di bawah layar — itu tanda kamu sedang di dalam tmux.

Split Pane: Banyak Jendela dalam Satu Layar

Salah satu fitur andalan tmux adalah split pane, jadi kamu bisa bagi layar jadi beberapa bagian. Misal, kamu mau lihat log di atas dan ngetik perintah di bawah. Caranya:

Split horizontal (atas-bawah):

Ctrl+b lalu "

Split vertical (kiri-kanan):

Ctrl+b lalu %

Untuk pindah antara pane, tekan Ctrl+b lalu tombol panah arah yang kamu mau. Praktis kan?

Detach dan Attach Session

Ini bagian paling penting. Detach artinya kamu keluar dari session tapi prosesnya tetap jalan di background. Caranya:

Ctrl+b lalu d

Setelah detach, kamu bakal kembali ke terminal biasa. Semua yang tadi jalan di tmux tetap aman. Nah, kalau mau masuk lagi ke session tersebut, gunakan perintah attach:

tmux attach -t belajar

Ganti "belajar" dengan nama session kamu. Atau kalau kamu lupa nama session-nya, ketik:

tmux ls

Itu akan menampilkan semua session yang sedang aktif.

Kenapa Tmux Berguna untuk Automation di Android?

Android itu sistem yang suka "membersihkan" aplikasi di background buat hemat bateri. Kalau kamu ngerun task penting, bisa aja Termux di-kill sistem. Dengan tmux, kamu bisa detach session dan membiarkan proses tetap jalan. Ini sangat berguna untuk:

  • Menjalankan bot Telegram atau Discord
  • Backup otomatis ke cloud
  • Monitoring server atau website
  • Mengetik perintah panjang tanpa takut terganggu notifikasi

Dengan tmux, HP Android kamu bisa mini server yang selalu siap. Cukup attach session kapan pun kamu butuh.

Penutup

Tmux mungkin terlihat sedikit membingungkan di awal, tapi setelah biasa, kamu bakal ngerasa sangat terbantu. Mulai dari bikin session, split pane, sampai detach/attach — semua bisa dikuasai dalam hitungan menit. Jadi, coba langsung praktikkan di Termux kamu. Selamat mencoba!

Vim punya tiga mode utama yang sering dipakai:

Normal mode — Ini mode default pas kamu buka Vim. Di sini kamu bisa navigasi, hapus teks, copy, paste, dan lain-lain. Tekan Esc buat balik ke mode ini kapan aja.

Insert mode — Mode buat ngetik teks. Tekan i sebelum kursor, a sesudah kursor, atau o buat baris baru. Kalau udah selesai ngetik, tekan Esc buat kembali ke normal mode.

Visual mode — Mode buat milih teks. Tekan v buat milih per karakter, V buat milih per baris, atau Ctrl+v buat milik per blok. Ini berguna kalau mau copy atau hapus sebagian teks.

Perintah Dasar yang Sering Dipakai

Nah ini bagian paling penting. Hafalin perintah-perintah ini biar nggak bingung:

Cari kata: Di normal mode, ketik / terus kata yang mau dicari, lalu Enter. Tekan n buat lanjut ke hasil berikutnya, N buat mundur.

Ganti kata: Ketik :s/lama/baru/ buat ganti di baris aktif. Tambahkan g di akhir (:s/lama/baru/g) buat ganti semua di baris itu. Buat ganti di seluruh file, pakai :s/lama/baru/g atau :1,$s/lama/baru/g.

set tabstop=4
set shiftwidth=4
set expandtab
syntax on
set autoindent
set hlsearch
set incsearch

Penjelasan singkat: set number nampilin nomor baris, tabstop dan shiftwidth ngatur ukuran tab, expandtab ngubah tab jadi spasi, syntax on ngaktifin pewarnaan kode, autoindent bikin otomatis indentasi, dan hlsearch plus incsearch bikin pencarian lebih keren.

Setelah disimpan, konfigurasi ini bakal otomatis aktif tiap kali kamu buka Vim.

Membuat SSH Key di Termux

7 Oktober 2026 · 6 menit baca

Pernah nggak sih, lagi asik coding di HP terus mau push ke GitHub tapi diminta password terus? Atau malah nggak bisa push sama sekali? Nah, solusinya adalah pakai SSH key. Dengan SSH key, kamu bisa connect ke GitHub tanpa perlu ngetik password lagi. Praktis banget, apalagi kalau kamu sering banget push-pull dari Termux.

Apa itu SSH key?

SSH key adalah sepasang kunci kriptografi yang digunakan untuk autentikasi aman antara HP kamu dan server GitHub. Ada dua kunci: private key (disimpan di HP, jangan pernah bagikan) dan public key (di-upload ke GitHub). Kalau cocok, koneksi langsung terbuka tanpa password.

Kenapa perlu SSH key?

  • Tanpa password — push/pull langsung jadi, nggak perlu ngetik password terus
  • Lebih aman — kunci kriptografi lebih sulit dibobol daripada password
  • Automatis — sekali setup, selamanya langsung connect

Langkah 1: Generate SSH key

Buka Termux dan jalankan perintah berikut:

ssh-keygen -t ed25519 -C "email-kamu@gmail.com"

Kalau diminta lokasi file, tekan Enter buat pakai default. Kalau diminta passphrase, bisa dikosongkan (tekan Enter dua kali) atau diisi buat keamanan ekstra.

Langkah 2: Copy public key

Setelah generate selesai, copy public key ke clipboard:

cat ~/.ssh/id_ed25519.pub

Blok semua teks yang muncul, lalu copy. Atau kalau kamu pakai Termux API:

termux-clipboard-set < ~/.ssh/id_ed25519.pub

Langkah 3: Tambah ke GitHub

  1. Buka github.com di browser
  2. Ke Settings → SSH and GPG keys
  3. Klik New SSH key
  4. Isi title (misal: "HP Android") dan paste public key
  5. Klik Add SSH key

Langkah 4: Test koneksi

Setelah SSH key ditambahkan, test koneksi dengan:

ssh -T git@github.com

Kalau berhasil, muncul pesan: Hi username! You've successfully authenticated...

Langkah 5: Ganti remote URL ke SSH

Kalau repo-mu masih pakai HTTP, ganti ke SSH:

git remote set-url origin git@github.com:username/repo.git

Sekarang push/pull langsung jalan tanpa password!

SSH key adalah investasi sekali setup, selamanya nggak perlu pusing password lagi.

Cara Backup Termux ke GitHub

7 Oktober 2026 · 5 menit baca

Buat kamu yang suka ngutak-atik Termux, pasti pernah ngerasa was-was kan? Takut HP hilang, takut data penting ilang, atau takut semua konfigurasi yang udah susah-susun harus ulang dari nol. Salah satu cara termudah adalah memanfaatkan GitHub sebagai tempat penyimpanan.

"Backup yang tidak pernah diuji itu bukan backup, itu hanya harapan." — Pepatah sysadmin

Kenapa Backup Penting?

HP Android itu rawan. Bisa jatuh, bisa hilang, bisa kena virus, atau bisa juga kamu salah hapus file. Kalau kamu sudah menghabiskan waktu berjam-jam mengatur Termux — install package, bikin script, atau setup environment — tentu tidak mau kan harus mengulang semua itu? Dengan backup otomatis ke GitHub, kamu bisa tenang. Semua perubahan tercatat, dan kapan pun butuh, tinggal clone lagi.

Setup Git di Termux

Pertama, pastikan kamu sudah install git di Termux. Kalau belum, jalankan perintah berikut:

pkg update && pkg install git -y

Setelah itu, konfigurasi identitas git supaya commit kamu tercatat dengan benar:

git config --global user.name "Nama Kamu"
git config --global user.email "email@kamu.com"

Selanjutnya, kamu butuh token GitHub untuk autentikasi. Buat token di halaman GitHub Settings → Developer settings → Personal access tokens. Simpan token itu baik-baik karena tidak akan ditampilkan lagi.

Buat Repo GitHub

Langkah selanjutnya adalah membuat repository di GitHub. Kamu bisa lewat website atau pakai GitHub CLI. Kalau pakai website, cukup klik tombol "New repository", beri nama misalnya termux-backup, dan pilih Private supaya hanya kamu yang bisa lihat.

Setelah repo dibuat, inisialisasi git di folder home Termux:

cd ~
git init
git add .
git commit -m "Initial backup"

Lalu, hubungkan repo lokal kamu ke GitHub:

git remote add origin https://github.com/username/termux-backup.git
git branch -M main
git push -u origin main

Saat diminta password, masukkan token GitHub yang tadi kamu buat. Jangan pakai password biasa karena GitHub sudah tidak mendukung itu lagi.

Push Otomatis dengan Cron

Biar tidak repot manual push setiap ada perubahan, kita bisa pakai cron. Pertama, install cronie:

pkg install cronie -y

Lalu, buat script backup sederhana:

#!/bin/bash
cd ~
git add .
git commit -m "Auto backup $(date)"
git push origin main

Simpan script itu sebagai backup.sh, lalu beri izin eksekusi:

chmod +x backup.sh

Terakhir, tambahkan cron job untuk menjalankannya tiap hari jam 2 pagi:

crontab -e
# Tambahkan baris ini:
0 2 * * * ~/backup.sh

Dengan setup ini, setiap perubahan di home directory Termux akan otomatis ter-backup ke GitHub. Praktis, kan?

Bot yang menjawab “saya tidak tahu” jelas masih hidup. Bot yang tidak menjawab sama sekali akan dianggap mati, dan itu asumsi yang paling mahal karena membuat pengguna menyangka programnya rusak.

Normalisasi sebelum mencocokkan

Pengguna tidak mengetik persis seperti dokumentasi. Ia bisa menulis Status, /status, atau status@bot_anda. Ketiganya perintah yang sama. Kalau pencocokan dilakukan mentah-mentah:

Masukan penggunaHarus dianggap sebagai
statusperintah status
Statusperintah status
/STATUSperintah status
status@bot_andaperintah status
halotidak dikenal, tetap dibalas

Normalisasi harus menjadi baris pertama, sebelum logika apa pun. Detail kecil ini yang menentukan apakah bot terasa pintar atau terasa kaku.

Menguji tanpa mengirim apa pun

Jangan langsung menguji program ke pengguna. Ganti fungsi pengirim dengan stub yang hanya mencatat:

terkirim = []

def kirim(teks):
    terkirim.append(teks)

# ... jalankan setiap perintah ...

for masukan in (biasanya, kapital, tak_dikenal, bersuffix):
    jalankan(masukan)
    assert terkirim, "masukan tidak dibalas: " + masukan

Untuk bot yang mengelola data sensitif, stub ini jauh lebih penting. Jangan pernah memanggil fungsi yang berdampak nyata di dalam pengujian. Sekali eksekusi nyata terjadi, tidak ada tombol batal.

Daftar periksa sebelum menyebut selesai

  1. Proses benar-benar ada — cek PID, bukan hanya “perintah dijalankan”
  2. Log punya isi — proses bisa berstatus jalan padahal keluarannya tertahan buffer
  3. Balasan benar-benar sampai — kirim dari akun lain, bukan dari chat sendiri
  4. Perintah tak dikenal tetap dibalas
  5. Offset tersimpan setelah restart sehingga pesan lama tidak diputar ulang

Penutup

Automasi yang jalan sendiri terasa mengagumkan. Tapi yang bisa diperintah dari Telegram itulah yang sebenarnya berguna. Kalau programnya masih hanya dikendalikan lewat keyboard, itu script yang dijadwalkan, bukan sistem.

Dan bagian yang paling sering terlupakan: program yang diam adalah program yang tidak bisa dipercaya, bukan program yang sedang bekerja dengan baik.

Termux punya batas nyata. Android bisa Hemat baterai atau membekukan aplikasi di latar belakang, jadi proses cron tidak dijamin hidup 24 jam. Untuk kebutuhan yang harus selalu nyala, lebih baik andalkan hosting.

Yang bisa dijalankan di HP: laporan, pengingat, pengecekan data. Yang tidak: mengelola aplikasi lain, membaca pesan, atau mengendalikan layar.

Cara Menghemat Kuota Internet di HP Android

Kuota internet habis sebelum akhir bulan itu menyebalkan. Berikut cara mengurangi pemakaian kuota tanpa mengurangi kenyamanan.

1. Aktifkan Data Saver

Android punya fitur bawaan yang mengurangi pemakaian data di latar belakang:

Pengaturan → Jaringan & internet → Data Saver → Aktifkan

Dengan ini, aplikasi yang tidak aktif tidak akan memakai data. Aplikasi yang sedang dipakai tetap berjalan normal.

2. Batasi pemakaian data di latar belakang

Beberapa aplikasi terus memakai data meski tidak dibuka. Cara membatasinya:

  1. Buka Pengaturan → Aplikasi
  2. Pilih aplikasi yang boros data
  3. Tap Data seluler
  4. Matikan Izinkan data latar belakang

Prioritaskan aplikasi seperti Instagram, TikTok, dan YouTube yang paling banyak memakan kuota.

3. Unduh video dan musik, bukan streaming

Streaming video atau musik terus-menerus menghabiskan kuota. Kalau sering menonton konten yang sama, unduh sekali lalu tonton berulang kali tanpa kuota.

YouTube Premium dan Spotify punya fitur unduh resmi. Untuk konten lain, banyak aplikasi unduh yang tersedia di Play Store.

4. Kompres gambar sebelum dikirim

Gambar dari kamera HP sekarang ukurannya besar. Sebelum dikirim lewat WhatsApp atau Telegram, kompres dulu:

  • Gunakan aplikasi seperti Photo Compressor
  • Atau aktifkan kompresi otomatis di WhatsApp: Pengaturan → Penyimpanan dan data → Unggah kualitas

5. Matikan pembaruan otomatis

Pembaruan aplikasi bisa memakan ratusan MB tanpa disadari. Atur agar pembaruan hanya terjadi saat terhubung Wi-Fi:

Play Store → Pengaturan → Preferensi jaringan → Pembaruan aplikasi otomatis → Hanya melalui Wi-Fi

6. Pantau pemakaian data

Android punya fitur pemantau data bawaan. Atur batas bulanan agar HP otomatis mematikan data saat kuota hampir habis:

Pengaturan → Jaringan & internet → Data Saver → Batas data

Cara Mengatasi HP Android yang Lemot

15 Oktober 2026 · 6 menit baca

HP Android yang tadinya lancar bisa menjadi lemot seiring waktu. Berikut cara mengembalikan performanya tanpa harus membeli HP baru.

1. Restart secara berkala

Langkah paling sederhana yang paling sering dilewatkan. Restart membersihkan memori dan menghentikan proses yang tidak perlu. Minimal sekali seminggu.

2. Hapus aplikasi yang tidak dipakai

Aplikasi yang terinstall tapi tidak dipakai tetap memakan ruang penyimpanan dan kadang berjalan di latar belakang. Buka Pengaturan → Aplikasi, urutkan berdasarkan terakhir dipakai, hapus yang sudah tidak relevan.

3. Bersihkan cache

Cache adalah data sementara yang disimpan aplikasi agar loading lebih cepat. Tapi cache yang menumpuk justru memperlambat HP:

Pengaturan → Penyimpanan → Data cache → Hapus

Atau per aplikasi: Pengaturan → Aplikasi → [nama aplikasi] → Hapus cache

4. Kurangi animasi

Animasi transisi yang halus membuat HP terasa responsif, tapi juga memakan resources. Untuk HP spesifikasi rendah, kurangi animasi:

  1. Aktifkan Opsi pengembang: Pengaturan → Tentang ponsel → ketuk Nomor build 7 kali
  2. Buka Pengaturan → Sistem → Opsi pengembang
  3. Ubah Skala animasi jendela, Skala animasi transisi, dan Skala durasi animasi menjadi 0.5x atau Matikan

5. Gunakan versi lite aplikasi

Banyak aplikasi populer punya versi lite yang lebih ringan:

  • Facebook Lite, Messenger Lite
  • Twitter Lite
  • Shopee Lite

Versi lite memakai lebih sedikit RAM dan storage, cocok untuk HP spesifikasi menengah ke bawah.

6. Perbarui sistem dan aplikasi

Pembaruan sering membawa perbaikan performa dan bug fix. Pastikan sistem Android dan aplikasi selalu versi terbaru.

7. Reset pabrik sebagai opsi terakhir

Kalau semua cara di atas tidak membantu, reset pabrik bisa mengembalikan HP seperti baru. Penting: backup semua data penting terlebih dahulu.

Pengaturan → Sistem → Opsi reset → Hapus semua data (reset pabrik)

Kapan harus ganti HP

Kalau HP sudah di atas 4 tahun, RAM di bawah 2 GB, dan prosesor sudah tertinggal, optimasi software hanya bisa membantu sebatas tertentu. Tapi untuk HP usia 2-3 tahun, cara di atas biasanya cukup mengembalikan performa.

HP lemot bukan selalu soal hardware tua. Seringkali itu soal software yang menumpuk dan tidak dirawat.

Dengan perawatan rutin, HP Android bisa tetap lancar bertahun-tahun.

  • Google Voice — gratis untuk pengguna AS, bisa menerima SMS verifikasi
  • TextNow — gratis, tersedia di Android dan iOS
  • Receive SMS — situs yang menyediakan nomor sementara untuk menerima SMS

Cara pakai: install aplikasi, dapatkan nomor, lalu gunakan untuk verifikasi seperti biasa.

  • Twitter / X — bisa daftar dengan email
  • Reddit — cukup email
  • Medium — cukup email
  • Quora — cukup email

Untuk platform yang mewajibkan nomor HP, coba daftar dengan email dulu, lalu lewati langkah verifikasi kalau memungkinkan.

Cara 3: pakai nomor keluarga

Kalau kamu tidak punya nomor virtual, gunakan nomor anggota keluarga yang sudah dewasa dan kamu percaya. Jelaskan kebutuhanmu, lalu minta izin.

Cara 4: pakai aplikasi penerima SMS
