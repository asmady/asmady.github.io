Automasi dengan Python di Termux: Dari Script ke Scheduler

8 Oktober 2026 · 6 menit baca

Sudah install Python di Termux tapi belum tahapakenya untuk otomasi? Artikel ini bantu kamu bikin script sederhana yang bisa dijalankan otomatis tiap hari.

Script Sederhana untuk Cek Storage

#!/usr/bin/env python3
import os

def cek_storage():
    total = os.statvfs('.').f_blocks * os.statvfs('.').f_frsize
    free = os.statvfs('.').f_bfree * os.statvfs('.').f_frsize
    used = total - free
    print(f"Total: {total / 1024 / 1024:.1f} MB")
    print(f"Free: {free / 1024 / 1024:.1f} MB")
    print(f"Used: {used / 1024 / 1024:.1f} MB")

if __name__ == "__main__":
    cek_storage()

Script ini cuma amati ukuran storage di home directory. Kamu bisa modifikasi untuk ngecek file mana yang besar, atau bahkan ngering notifikasi kalau storage hampir penuh.

Menyimpan Script ke File

  1. Buka Termux dan ketik nano otomatisasi.py
  2. Copy script di atas ke dalam editor
  3. Simpan dengan Ctrl+O, Enter, lalu Ctrl+X
  4. Jalankan dengan python otomatisasi.py

Keluaran akan tampil di terminal berisi ukuran storage dalam MB.

Menjadwalkan dengan Cron

  1. Buat script backup di ~/otomatisasi.sh:
#!/bin/bash
cd ~
python otomatisasi.py > /storage/emulated/0/otomatisasi_log.txt 2>&1
  1. Berikan izin eksekusi:
chmod +x ~/otomatisasi.sh
  1. Tambah ke cron tiap pagi jam 8:
crontab -e
0 8 * * * ~/otomatisasi.sh

Dengan begitu, tiap pagi jam 8, script Python akan jalan dan log akan disimpan di storage HP.

Python di Termux Bisa jadi alat otomatisasi yang kuat, dari cek sederhana sampai script yang kompleks.

Dengan script di atas, kamu sudah bisa mulai otomatisasi pekerjaan rutin di Termux pakai Python. Coba satu per satu, mulai dari script sederhana dan tambah fiturnya bertahap.

Affiliate Marketing untuk Pemula

8 Oktober 2026 · 7 menit baca

Mau dapat penghasilan tambahan dari internet tapi tidak punya produk sendiri? Affiliate marketing bisa jadi solusinya. Kamu promosi produk orang lain, dan dapat komisi setiap ada yang beli lewat link kamu.

Apa itu Affiliate Marketing?

Affiliate marketing adalah model bisnis di mana kamu mempromosikan produk atau jasa orang lain. Setiap ada pembelian yang terjadi lewat link referral kamu, kamu mendapat komisi. Komisi bervariasi, mulai dari 1% sampai 50% bahkan lebih.

Kenapa Affiliate Marketing Cocok untuk Pemula?

  • Tidak perlu produk — Jual produk orang lain
  • Tidak perlu customer service — Vendor yang handle
  • Modal kecil — Cuma butuh website atau media sosial
  • Passive income — Link tetap aktif 24 jam

Langkah 1: Pilih Niche

Pilih niche yang kamu pahami dan minati. Contoh: teknologi, kesehatan, keuangan, atau lifestyle. Niche yang spesifik biasanya lebih mudah daripada yang terlalu umum.

Langkah 2: Daftar Program Affiliate

Banyak program affiliate yang bisa diikuti:

  • Amazon Associates — Komisi 1-10% per produk
  • Shopee Affiliate — Komisi hingga 20%
  • Tokopedia Affiliate — Komisi bervariasi
  • Digital products — Komisi 30-50% (ebook, course, software)

Langkah 3: Buat Konten

Buat konten yang membantu audiens. Bukan sekadar promosi, tapi review, tutorial, atau perbandingan produk. Konten yang berkualitas akan menghasilkan konversi lebih tinggi.

Langkah 4: Promosikan

Sebarkan link affiliate kamu di:

  • Blog atau website
  • Media sosial (Instagram, TikTok, Twitter)
  • Email newsletter
  • YouTube channel

Langkah 5: Tracking dan Analisis

Pantau performa link affiliate kamu. Tools yang bisa dipakai:

  • Google Analytics — Track traffic dan konversi
  • Bitly — Short link dengan tracking
  • Spreadsheet — Catat manual klik dan konversi

Dari data ini, kamu bisa tahu konten mana yang paling efektif dan produk mana yang paling laris.

Contoh Konten Affiliate yang Efektif

  • Review jujur — Sebut kelebihan dan kekurangan produk
  • Tutorial — Cara pakai produk dengan link affiliate
  • Perbandingan — Bandingkan 2-3 produk sejenis
  • Listicle — "5 produk terbaik untuk..."

Kesalahan yang Sering Dilakukan Pemula

  • Spam link — Promosi terlalu agresif tanpa nilai tambah
  • Produk tidak relevan — Jual produk yang tidak sesuai niche
  • Tidak disclose — Wajib beri tahu pembaca kalau link adalah affiliate
  • Menyerah terlalu cepat — Butuh 3-6 bulan untuk melihat hasil

Berapa Lama Bisa Menghasilkan?

Realistis: affiliate marketing bukan cara cepat kaya. Biasanya butuh 3-6 bulan konsisten sebelum melihat pendapatan yang signifikan. Kuncinya adalah konsistensi dan terus belajar dari data.

Legal dan Disclosure

Di banyak negara, kamu wajib mengungkapkan kalau link adalah affiliate. Tambahkan disclaimer di blog kamu:

"Artikel ini mengandung link affiliate. Jika Anda membeli melalui link ini, saya mendapat komisi tanpa biaya tambahan untuk Anda."

Tips Meningkatkan Konversi

  • Honest review — Jangan hanya puasakan, juga sebut kekurangan
  • Call to action jelas — "Klik link di bio" atau "Beli lewat link ini"
  • Tracking — Pantau link mana yang paling banyak klik
  • Konsisten — Affiliate marketing butuh waktu, jangan menyerah cepat
Affiliate marketing bukan skema cepat kaya. Tapi dengan konsistensi, bisa jadi penghasilan pasif yang signifikan.

Mulai dari satu niche, satu produk, satu konten. Pelan-pelan tapi pasti. Selamat mencoba!

Cara Pakai SSH di Termux

8 Oktober 2026 · 7 menit baca

Pernah ngerasa harus bawa laptop terus cuma buat connect ke server? Atau mau manage server tapi lagi di jalan? Dengan SSH di Termux, kamu bisa connect ke server mana saja langsung dari HP Android.

Apa itu SSH?

SSH (Secure Shell) adalah protocol untuk connect ke server secara aman. Semua data terenkripsi, jadi aman dipakai di jaringan public. SSH biasa dipakai untuk manage server, transfer file, dan remote command.

Install SSH Client

Termux sudah include SSH client secara default. Cek dengan:

ssh -V

Kalau belum ada, install dengan:

pkg install openssh

Connect ke Server

Format dasar SSH:

ssh username@ip_address

Contoh:

ssh root@192.168.1.100

Kalau port custom:

ssh -p 2222 root@192.168.1.100

SSH Key untuk Login Tanpa Password

Biar tidak perlu ketik password setiap login, setup SSH key:

ssh-keygen -t ed25519
ssh-copy-id root@192.168.1.100

Setelah ini, login langsung tanpa password.

Transfer File dengan SCP

SSH juga bisa dipakai transfer file:

# Upload file ke server
scp file.txt root@192.168.1.100:/root/

# Download file dari server
scp root@192.168.1.100:/root/file.txt ./

SSH Config File

Biar tidak perlu ketik panjang setiap kali, buat config file:

nano ~/.ssh/config

Isi dengan:

Host myserver
    HostName 192.168.1.100
    User root
    Port 22
    IdentityFile ~/.ssh/id_ed25519

Sekarang cukup ketik ssh myserver untuk connect.

SSH Tunnel

SSH tunnel bisa dipakai untuk mengakses service di server secara aman:

# Local tunnel - akses service di server dari HP
ssh -L 8080:localhost:80 root@192.168.1.100

Sekarang buka localhost:8080 di browser HP untuk akses web server di remote.

SSH Agent

SSH agent menyimpan key di memory sehingga tidak perlu ketik passphrase setiap kali:

eval $(ssh-agent)
ssh-add ~/.ssh/id_ed25519

Sekarang key sudah di-load dan bisa dipakai berulang kali tanpa passphrase.

Troubleshooting Error Umum

  • Connection refused — Server tidak jalan atau port salah
  • Permission denied — Username/password salah atau SSH key tidak cocok
  • Host key verification failed — Server ganti key, hapus dengan ssh-keygen -R ip_address
  • Connection timed out — Firewall memblokir atau IP salah

Tips Keamanan

  • Disable root login — Buat user biasa, login sebagai user lalu sudo
  • Change default port — Port 22 sering di-scan bot
  • Gunakan SSH key — Lebih aman dari password
  • Fail2ban — Block IP yang terlalu banyak gagal login
SSH adalah jendela ke server mana saja. Dengan Termux, server ada di saku kamu.

Sekarang kamu bisa manage server dari mana saja tanpa bawa laptop. Selamat mencoba!

AI untuk Konten Blog

8 Oktober 2026 · 6 menit baca

Banyak blogger pemula yang bingung mulai dari mana saat menulis artikel. Ide sulit datang, blank page syndrome melanda, dan akhirnya artikel tidak pernah selesai. Untungnya, sekarang ada AI yang bisa membantu proses menulis konten blog.

AI Bukan Pengganti, Tapi Asisten

Penting untuk dipahami: AI bukan pengganti kamu sebagai penulis. AI adalah asisten yang membantu mempercepat proses. Kamu tetap yang menentukan topik, struktur, dan pesan utama. AI membantu mengembangkan ide, menulis draft, dan memperbaiki grammar.

Langkah 1: Brainstorming dengan AI

Mulai dengan minta AI untuk memberikan ide artikel berdasarkan niche kamu. Contoh prompt:

"Beri saya 10 ide artikel tentang [niche kamu] untuk pemula"

AI akan memberikan daftar ide yang bisa kamu pilih. Pilih yang paling relevan dengan audiens kamu.

Langkah 2: Buat Outline

Setelah dapat ide, minta AI untuk membuat outline artikel:

"Buat outline artikel tentang [judul], target pembaca pemula"

Outline ini menjadi panduan kamu menulis. Kamu tidak perlu mengikuti mentah-mentah, tapi punya struktur yang jelas.

Langkah 3: Tulis Draft

Sekarang mulai tulis. Kamu bisa menulis sendiri berdasarkan outline, atau minta AI untuk menulis draft pertama:

"Tulis draft artikel tentang [judul], gaya santai, 500 kata"

Draft AI biasanya perlu diedit. Tambahkan pengalaman pribadi, contoh nyata, dan suara kamu sendiri.

Langkah 4: Edit dan Polish

Setelah draft selesai, minta AI untuk membantu edit:

"Perbaiki grammar dan buat lebih natural"

AI bisa membantu memperbaiki typo, grammar, dan membuat kalimat lebih mengalir.

Langkah 5: Optimasi SEO

Setelah artikel selesai, minta AI untuk optimasi SEO:

"Tambahkan meta description dan suggest keyword untuk artikel ini"

AI bisa membantu menemukan keyword yang relevan dan membuat meta description yang menarik.

Tools AI yang Bisa Dipakai

  • ChatGPT — Untuk brainstorming dan draft artikel
  • Claude — Untuk analisis dan editing mendalam
  • Grammarly — Untuk cek grammar dan style
  • Surfer SEO — Untuk optimasi SEO artikel

Contoh Workflow Lengkap

  1. Prompt: "Beri 5 ide artikel tentang produktivitas untuk remote worker"
  2. Pilih ide, minta outline
  3. Tulis draft berdasarkan outline (bantu AI)
  4. Edit dan tambahkan pengalaman pribadi
  5. Optimasi SEO dan publish

Tips Penting

  • Selalu review — AI bisa salah, cek fakta sebelum publish
  • Tambahkan personal touch — Pembaca ingin membaca pengalaman nyata
  • Jangan copy-paste mentah — Google bisa mendeteksi konten AI murni
  • Gunakan AI sebagai partner — Diskusi dengan AI, bukan sekadar perintah
AI adalah alat, bukan tongkat. Kamu tetap yang mengendalikan, AI yang membantu mempercepat.

Dengan workflow ini, kamu bisa menulis artikel lebih cepat tanpa mengorbankan kualitas. Selamat mencoba!

Monetisasi Blog dengan Google AdSense

7 Oktober 2026 · 8 menit baca

Punya blog tapi belum menghasilkan? Salah satu cara paling populer untuk monetisasi blog adalah dengan Google AdSense. AdSense menampilkan iklan di blog kamu, dan kamu dibayar setiap kali pengguna mengklik atau melihat iklan tersebut. Artikel ini bakal pandu kamu dari awal sampai approved.

Sebelum daftar, pastikan blog kamu memenuhi syarat:

  • Blog sudah punya konten original minimal 10-15 artikel

Cara Install dan Pakai Tmux di Termux

7 Oktober 2026 · 6 menit baca

Pernah ngerasa kesel karena HP Android kamu mati atau aplikasi ke-close, terus semua proses yang lalan tiba-tiba berhenti semua? Nah, di sinilah tmux jadi penyelamat. Tmux itu semacam terminal multiplexer, jadi kamu bisa bikin banyak "jendela" dalam satu terminal, dan yang paling penting: prosesnya tetap jalan walau kamu keluar dari Termux. Gampangnya, tmux bikin terminal kamu jadi lebih kuat dan tidak gampang mati.

Apa Itu Tmux?

Singkatnya, tmux (terminal multiplexer) itu alat yang memungkinkan kamu membuat, mengelola, dan berpindah antara beberapa sesi terminal dalam satu layar. Bayangkan kamu lagi ngerun script panjang, terus kamu mau buka aplikasi lain atau lock HP. Tanpa tmux, script-nya bakal berhenti. Dengan tmux, script tetap jalan di background. Ini sangat berguna buat kamu yang suka otomasi di Android, misalnya ngerun bot, cron job, atau server sederhana.

Cara Install Tmux di Termux

Install-nya gampang banget. Buka Termux, terus ketik perintah ini:

pkg update && pkg install tmux -y

Tunggu sampai selesai. Kalau sudah, coba cek versinya dengan:

tmux -V

Kalo muncul versi (misalnya tmux 3.x), berarti tmux sudah siap dipakai.

Membuat Session Baru

Session itu seperti "ruang kerja" di tmux. Kamu bisa bikin banyak session untuk beda-beda tujuan. Cara bikin session baru:

tmux new -s belajar

Di sini "belajar" adalah nama session-nya. Kamu bisa ganti terserah, misalnya bot, server, atau backup. Setelah perintah ini dijalankan, kamu bakal masuk ke session tmux. Perhatikan ada bar hijau di bawah layar — itu tanda kamu sedang di dalam tmux.

Split Pane: Banyak Jendela dalam Satu Layar

Salah satu fitur andalan tmux adalah split pane, jadi kamu bisa bagi layar jadi beberapa bagian. Misal, kamu mau lihat log di atas dan ngetik perintah di bawah. Caranya:

Split horizontal (atas-bawah):

Ctrl+b lalu "

Split vertical (kiri-kanan):

Ctrl+b lalu %

Untuk pindah antara pane, tekan Ctrl+b lalu tombol panah arah yang kamu mau. Praktis kan?

Detach dan Attach Session

Ini bagian paling penting. Detach artinya kamu keluar dari session tapi prosesnya tetap jalan di background. Caranya:

Ctrl+b lalu d

Setelah detach, kamu bakal kembali ke terminal biasa. Semua yang tadi jalan di tmux tetap aman. Nah, kalau mau masuk lagi ke session tersebut, gunakan perintah attach:

tmux attach -t belajar

Ganti "belajar" dengan nama session kamu. Atau kalau kamu lupa nama session-nya, ketik:

tmux ls

Itu akan menampilkan semua session yang sedang aktif.

Kenapa Tmux Berguna untuk Automation di Android?

Android itu sistem yang suka "membersihkan" aplikasi di background buat hemat bateri. Kalau kamu ngerun task penting, bisa aja Termux di-kill sistem. Dengan tmux, kamu bisa detach session dan membiarkan proses tetap jalan. Ini sangat berguna untuk:

  • Menjalankan bot Telegram atau Discord
  • Backup otomatis ke cloud
  • Monitoring server atau website
  • Mengetik perintah panjang tanpa takut terganggu notifikasi

Dengan tmux, HP Android kamu bisa mini server yang selalu siap. Cukup attach session kapan pun kamu butuh.

Penutup

Tmux mungkin terlihat sedikit membingungkan di awal, tapi setelah biasa, kamu bakal ngerasa sangat terbantu. Mulai dari bikin session, split pane, sampai detach/attach — semua bisa dikuasai dalam hitungan menit. Jadi, coba langsung praktikkan di Termux kamu. Selamat mencoba!

Mode-Mode Vim yang Wajib Tahu

Vim punya tiga mode utama yang sering dipakai:

Normal mode — Ini mode default pas kamu buka Vim. Di sini kamu bisa navigasi, hapus teks, copy, paste, dan lain-lain. Tekan Esc buat balik ke mode ini kapan aja.

Insert mode — Mode buat ngetik teks. Tekan i sebelum kursor, a sesudah kursor, atau o buat baris baru. Kalau udah selesai ngetik, tekan Esc buat kembali ke normal mode.

Visual mode — Mode buat milih teks. Tekan v buat milih per karakter, V buat milih per baris, atau Ctrl+v buat milik per blok. Ini berguna kalau mau copy atau hapus sebagian teks.

Perintah Dasar yang Sering Dipakai

Nah ini bagian paling penting. Hafalin perintah-perintah ini biar nggak bingung:

Simpan file: Ketik :w lalu Enter. Kalau mau simpan sebagai file baru, pakai :w namafile.

Keluar dari Vim: Ketik :q lalu Enter. Kalau ada perubahan yang belum disimpan, Vim bakal nolak. Pakai :q! buat keluar tanpa menyimpan.

Simpan dan keluar sekaligus: Ketik :wq atau :x lalu Enter. Ini perintah paling sering dipakai.

Cari kata: Di normal mode, ketik / terus kata yang mau dicari, lalu Enter. Tekan n buat lanjut ke hasil berikutnya, N buat mundur.

Ganti kata: Ketik :s/lama/baru/ buat ganti di baris aktif. Tambahkan g di akhir (:s/lama/baru/g) buat ganti semua di baris itu. Buat ganti di seluruh file, pakai :s/lama/baru/g atau :1,$s/lama/baru/g.

Konfigurasi .vimrc Sederhana

Biar Vim lebih nyaman dipakai, kamu bisa bikin file konfigurasi .vimrc di home directory. Caranya:

vim ~/.vimrc

Lalu tambahkan konfigurasi dasar ini:

set number
set tabstop=4
set shiftwidth=4
set expandtab
syntax on
set autoindent
set hlsearch
set incsearch

Penjelasan singkat: set number nampilin nomor baris, tabstop dan shiftwidth ngatur ukuran tab, expandtab ngubah tab jadi spasi, syntax on ngaktifin pewarnaan kode, autoindent bikin otomatis indentasi, dan hlsearch plus incsearch bikin pencarian lebih keren.

Setelah disimpan, konfigurasi ini bakal otomatis aktif tiap kali kamu buka Vim.

Tips Tambahan

Kalau kamu masih pemula, jangan langsung belajar semua perintah sekaligus. Mulai dari yang paling dasar: buka file, ngetik, simpan, keluar. Lama-lama kamu bakal terbiasa dan makin jago. Jangan lupa buat latihan rutin, minimal 15 menit sehari. Vim itu soal kebiasaan, bukan soal hafalan.

Membuat SSH Key di Termux

7 Oktober 2026 · 6 menit baca

Pernah nggak sih, lagi asik coding di HP terus mau push ke GitHub tapi diminta password terus? Atau malah nggak bisa push sama sekali? Nah, solusinya adalah pakai SSH key. Dengan SSH key, kamu bisa connect ke GitHub tanpa perlu ngetik password lagi. Praktis banget, apalagi kalau kamu sering banget push-pull dari Termux.

Apa itu SSH key?

SSH key adalah sepasang kunci kriptografi yang digunakan untuk autentikasi aman antara HP kamu dan server GitHub. Ada dua kunci: private key (disimpan di HP, jangan pernah bagikan) dan public key (di-upload ke GitHub). Kalau cocok, koneksi langsung terbuka tanpa password.

Kenapa perlu SSH key?

  • Tanpa password — push/pull langsung jadi, nggak perlu ngetik password terus
  • Lebih aman — kunci kriptografi lebih sulit dibobol daripada password
  • Automatis — sekali setup, selamanya langsung connect

Langkah 1: Generate SSH key

Buka Termux dan jalankan perintah berikut:

ssh-keygen -t ed25519 -C "email-kamu@gmail.com"

Kalau diminta lokasi file, tekan Enter buat pakai default. Kalau diminta passphrase, bisa dikosongkan (tekan Enter dua kali) atau diisi buat keamanan ekstra.

Langkah 2: Copy public key

Setelah generate selesai, copy public key ke clipboard:

cat ~/.ssh/id_ed25519.pub

Blok semua teks yang muncul, lalu copy. Atau kalau kamu pakai Termux API:

termux-clipboard-set < ~/.ssh/id_ed25519.pub

Langkah 3: Tambah ke GitHub

  1. Buka github.com di browser
  2. Ke Settings → SSH and GPG keys
  3. Klik New SSH key
  4. Isi title (misal: "HP Android") dan paste public key
  5. Klik Add SSH key

Langkah 4: Test koneksi

Setelah SSH key ditambahkan, test koneksi dengan:

ssh -T git@github.com

Kalau berhasil, muncul pesan: Hi username! You've successfully authenticated...

Langkah 5: Ganti remote URL ke SSH

Kalau repo-mu masih pakai HTTP, ganti ke SSH:

git remote set-url origin git@github.com:username/repo.git

Sekarang push/pull langsung jalan tanpa password!

SSH key adalah investasi sekali setup, selamanya nggak perlu pusing password lagi.

Cara Backup Termux ke GitHub

7 Oktober 2026 · 5 menit baca

Buat kamu yang suka ngutak-atik Termux, pasti pernah ngerasa was-was kan? Takut HP hilang, takut data penting ilang, atau takut semua konfigurasi yang udah susah-susun harus ulang dari nol. Salah satu cara termudah adalah memanfaatkan GitHub sebagai tempat penyimpanan.

"Backup yang tidak pernah diuji itu bukan backup, itu hanya harapan." — Pepatah sysadmin

Kenapa Backup Penting?

HP Android itu rawan. Bisa jatuh, bisa hilang, bisa kena virus, atau bisa juga kamu salah hapus file. Kalau kamu sudah menghabiskan waktu berjam-jam mengatur Termux — install package, bikin script, atau setup environment — tentu tidak mau kan harus mengulang semua itu? Dengan backup otomatis ke GitHub, kamu bisa tenang. Semua perubahan tercatat, dan kapan pun butuh, tinggal clone lagi.

Setup Git di Termux

Pertama, pastikan kamu sudah install git di Termux. Kalau belum, jalankan perintah berikut:

pkg update && pkg install git -y

Setelah itu, konfigurasi identitas git supaya commit kamu tercatat dengan benar:

git config --global user.name "Nama Kamu"
git config --global user.email "email@kamu.com"

Selanjutnya, kamu butuh token GitHub untuk autentikasi. Buat token di halaman GitHub Settings → Developer settings → Personal access tokens. Simpan token itu baik-baik karena tidak akan ditampilkan lagi.

Buat Repo GitHub

Langkah selanjutnya adalah membuat repository di GitHub. Kamu bisa lewat website atau pakai GitHub CLI. Kalau pakai website, cukup klik tombol "New repository", beri nama misalnya termux-backup, dan pilih Private supaya hanya kamu yang bisa lihat.

Setelah repo dibuat, inisialisasi git di folder home Termux:

cd ~
git init
git add .
git commit -m "Initial backup"

Lalu, hubungkan repo lokal kamu ke GitHub:

git remote add origin https://github.com/username/termux-backup.git
git branch -M main
git push -u origin main

Saat diminta password, masukkan token GitHub yang tadi kamu buat. Jangan pakai password biasa karena GitHub sudah tidak mendukung itu lagi.

Push Otomatis dengan Cron

Biar tidak repot manual push setiap ada perubahan, kita bisa pakai cron. Pertama, install cronie:

pkg install cronie -y

Lalu, buat script backup sederhana:

#!/bin/bash
cd ~
git add .
git commit -m "Auto backup $(date)"
git push origin main

Simpan script itu sebagai backup.sh, lalu beri izin eksekusi:

chmod +x backup.sh

Terakhir, tambahkan cron job untuk menjalankannya tiap hari jam 2 pagi:

crontab -e
# Tambahkan baris ini:
0 2 * * * ~/backup.sh

Dengan setup ini, setiap perubahan di home directory Termux akan otomatis ter-backup ke GitHub. Praktis, kan?

Bot yang menjawab “saya tidak tahu” jelas masih hidup. Bot yang tidak menjawab sama sekali akan dianggap mati, dan itu asumsi yang paling mahal karena membuat pengguna menyangka programnya rusak.

Untuk bot yang mengelola data sensitif, stub ini jauh lebih penting. Jangan pernah memanggil fungsi yang berdampak nyata di dalam pengujian. Sekali eksekusi nyata terjadi, tidak ada tombol batal.

  2. Log punya isi — proses bisa berstatus jalan padahal keluarannya tertahan buffer
  3. Balasan benar-benar sampai — kirim dari akun lain, bukan dari chat sendiri

Cara Pakai Runit di Termux: Auto-restart Service

9 Oktober 2026 · 6 menit baca

Pernah bikin bot atau script di Termux, tapi kalau HP restart semua berhenti? Runit adalah service manager lightweight yang bisa auto-restart aplikasi saat HP dinyalakan ulang. Artikel ini bantu kamu setup runit dari nol.

Apa itu Runit?

Runit adalah init system dan service manager untuk Unix-like systems. Di Termux, runit berguna untuk menjaga script, bot, atau server tetap jalan otomatis. Kalau process mati karena alasan apa pun, runit akan restart secara otomatis.

Install Runit di Termux

pkg update && pkg install runit -y

Setelah install, runit siap dikonfigurasi. Tidak perlu setup tambahan untuk penggunaan dasar.

Membuat Service Baru

  1. Buat folder service:
mkdir -p ~/service/bot-ku
  1. Buat file run:
nano ~/service/bot-ku/run
  1. Isi dengan script yang mau dijalankan:
#!/bin/bash
cd ~/bot-ku
while true; do
  python3 bot.py
  sleep 5
done
  1. Berikan izin eksekusi:
chmod +x ~/service/bot-ku/run

Menjalankan Service

Untuk menjalankan service dengan runit:

runsv ~/service/bot-ku &

Service akan berjalan di background. Kalau process di dalamnya mati, runsv akan otomatis restart sesuai interval yang ditentukan.

Auto-start saat HP Boot

Biar service jalan otomatis saat HP dinyalakan, tambahkan ke boot script. Edit file ~/.termux/boot/start-runit.sh:

#!/bin/bash
# Tunggu Termux siap
sleep 10

# Jalankan semua service
for svc in ~/service/*/; do
  if [ -f "$svc/run" ]; then
    runsv "$svc" &
  fi
done

Berikan izin eksekusi: chmod +x ~/.termux/boot/start-runit.sh

Menghentikan Service

Untuk menghentikan service:

svc -d ~/service/bot-ku

Untuk menghapus service, hentikan dulu lalu hapus folder:

svc -d ~/service/bot-ku
rm -rf ~/service/bot-ku

Tips Penting

  • Log — Selalu simpan log service ke file untuk debugging
  • Resource — Jangan jalankan terlalu banyak service, hemat RAM dan baterai
  • Testing — Jalankan manual dulu sebelum ke runit untuk memastikan tidak ada error
Runit adalah cara paling sederhana dan reliable untuk menjaga script tetap hidup di HP Android tanpa root.

Dengan runit, bot atau automation kamu tidak akan mati lagi saat HP restart. Setup sekali, selamanya tenang.

Cara Pakai GitHub Actions untuk Otomasi Blog

10 Oktober 2026 · 7 menit baca

Setiap kali nambah artikel baru, kamu harus commit, push, dan tunggu GitHub Pages update. Kalau sering posting, proses ini bisa membosankan. Dengan GitHub Actions, semua proses ini bisa diotomatisasi. Artikel ini bantu kamu setup CI/CD untuk blog GitHub Pages dari nol.

Apa itu GitHub Actions?

GitHub Actions adalah tool CI/CD (Continuous Integration/Continuous Deployment) bawaan GitHub. Dengan Actions, kamu bisa menjalankan workflow otomatis setiap kali ada perubahan di repository. Misalnya: setiap kali push ke main, otomatis build dan deploy ke GitHub Pages.

Struktur File Workflow

File workflow disimpan di folder .github/workflows/ di root repository. File berformat YAML. Berikut contoh workflow sederhana untuk deploy ke GitHub Pages:

name: Deploy to GitHub Pages

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./

Langkah Setup

  1. Buka repository blog kamu di GitHub
  2. Klik tab Settings
  3. Di sidebar kiri, klik Pages
  4. Bagian Source, pilih GitHub Actions (bukan Deploy from branch)
  5. Commit dan push file workflow di atas ke repository
  6. Setiap kali kamu push artikel baru, workflow akan otomatis jalan dan deploy

Keuntungan Otomasi

  • Tidak perlu deploy manual — Push artikel, selesai
  • Build otomatis — Kalau ada error, kamu dapat notifikasi
  • Gratis — GitHub Actions gratis untuk public repository
  • Rollback mudah — Kalau ada masalah, tinggal revert commit

Troubleshooting

Kalau workflow gagal, cek tab Actions di repository. Kamu bisa lihat log lengkap dan tahu di step mana error terjadi. Biasanya masalah umum adalah permission token atau path publish_dir yang salah.

Otomasi bukan untuk membuat kamu malas, tapi untuk fokus ke konten daripada proses teknis.

Dengan GitHub Actions, setiap artikel yang kamu push akan otomatis live tanpa perlu deploy manual. Lebih cepat, lebih efisien. Selamat mencoba!

Cara Pakai Termux API: Akses Sensor dan Fitur Android dari Terminal

10 Oktober 2026 · 7 menit baca

Termux bukan cuma terminal emulator. Dengan Termux API, kamu bisa mengakses fitur Android seperti notifikasi, SMS, lokasi, baterai, dan banyak lagi langsung dari terminal. Ini membuka banyak kemungkinan otomasi yang sebelumnya tidak bisa dilakukan.

Apa itu Termux API?

Termux API adalah package yang menyediakan akses ke fitur Android dari command line. Dengan ini, kamu bisa baca sensor, kirim notifikasi, akses clipboard, dan lain-lain tanpa perlu buat aplikasi Android.

Install Termux API

Pertama, install package Termux API di Termux:

pkg install termux-api

Selain itu, kamu juga perlu install aplikasi Termux:API dari Play Store atau F-Droid. Aplikasi ini yang menyediakan bridge antara Termux dan sistem Android.

Contoh Penggunaan Termux API

1. Kirim Notifikasi

termux-notification --title "Backup Selesai" --content "File sudah di-backup ke GitHub"

2. Baca Baterai

termux-battery-status

Outputnya JSON dengan info level baterai, status charging, dan suhu.

3. Akses Clipboard

termux-clipboard-set "Teks ini disimpan di clipboard"
termux-clipboard-get

4. Get Lokasi

termux-location

Butuh permission location. Outputnya latitude, longitude, dan altitude.

5. Kirim SMS

termux-sms-send -n "08123456789" "Pesan otomatis dari Termux"

6. Get Info WiFi

termux-wifi-connectioninfo

Contoh Automasi: Notifikasi Backup

Gabungkan Termux API dengan cron untuk backup otomatis dengan notifikasi:

#!/bin/bash
cd ~/blog-repo
git add .
git commit -m "Auto backup $(date)"
git push origin main
termux-notification --title "Backup" --content "Blog sudah di-backup"

Contoh Automasi: Cek Baterai

Script untuk cek baterai dan kirim notifikasi kalau baterai rendah:

#!/bin/bash
BATERAI=$(termux-battery-status | grep -o '"percentage": [0-9]*' | grep -o '[0-9]*')
if [ "$BATERAI" -lt 20 ]; then
  termux-notification --title "Baterai Rendah" --content "Baterai: $BATERAI%"
fi

Tips Keamanan

  • Hati-hati dengan SMS — Jangan kirim SMS otomatis tanpa filter
  • Location — Hanya akses lokasi kalau benar-benar perlu
  • Permission — Berikan permission yang diperlukan saja
Termux API membuka pintu otomasi Android yang sebelumnya hanya bisa dilakukan dengan aplikasi khusus.

Dengan Termux API, HP Android kamu bisa jadi alat otomasi yang powerful. Mulai dari yang sederhana, tambah kompleksitas bertahap.

  • Subject line — Menarik, jelas, dan tidak clickbait

  1. Welcome email — Kirim langsung setelah subscribe
