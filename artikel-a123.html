Vim di Termux: Belajar Editor Teks Paling Powerful di Terminal

20 Oktober 2026 · 7 menit baca

Vim adalah editor teks yang sudah ada sejak 1991 dan masih jadi standar di dunia Linux. Di Termux, Vim adalah editor paling powerful untuk mengedit konfigurasi, menulis script, atau coding langsung dari terminal HP Android. Kurva belajarnya curam, tapi setelah kamu paham dasar-dasarnya, tidak akan kembali ke editor lain.

Kenapa Vim dan Bukan Nano?

Nano mudah dipakai, tapi terbatas. Vim punya mode editing yang memungkinkan kamu navigasi dan edit tanpa mouse. Makin lama dipakai, makin cepat. Vim tersedia di hampir semua sistem Linux — kalau kamu bisa pakai Vim di Termux, kamu bisa pakai di mana saja.

Instalasi Vim di Termux

Perintahnya simpel: pkg install vim. Vim langsung tersedia. Untuk tampilan lebih bagus, install plugin manager vim-plug. Tapi untuk pemula, Vim default sudah cukup.

Mode-Mode Dasar Vim

Vim punya 3 mode utama: Normal mode (navigasi dan perintah), Insert mode (mengetik), dan Visual mode (blok teks). Cara paling cepat belajar: buka Vim, tekan i untuk insert, ketik teks, tekan Esc, ketik :wq untuk save dan quit.

Navigasi Tanpa Mouse

Di Normal mode: h untuk kiri, l untuk kanan, j untuk bawah, k untuk atas. gg untuk ke awal file, G untuk ke akhir. /kata untuk mencari. :nomor untuk lompat ke baris tertentu. Semua dengan keyboard saja.

Edit Cepat dengan Command

dd untuk hapus satu baris. yy untuk copy. p untuk tempel. u untuk undo. :%s/lama/baru/g untuk replace seluruh file. Command-command ini terasa aneh awalnya, tapi setelah 2 minggu akan jadi second nature.

Tips untuk Pemula

Mulai dengan 15 menit per hari. Pakai vimtutor — tutorial built-in yang bisa dijalankan langsung dari terminal Termux dengan perintah: vimtutor. Fokus ke navigasi dulu, baru ke command edit.

Kesimpulan

Vim adalah investasi skill yang tidak akan pernah usang. Di mana ada Linux, di situ ada Vim. Mulai dari hari ini, satu command per hari, dan dalam sebulan kamu akan paham mengapa Vim masih jadi raja editor teks.
