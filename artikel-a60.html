Cara Pakai Curl di Termux: HTTP Request dari Terminal

14 Oktober 2026 · 6 menit baca

curl adalah tools command-line buat ngirim HTTP request. Buat developer, sysadmin, atau siapa aja yang suka otomasi, curl itu wajib dikuasai. Dan kabar baiknya, curl bisa jalan di Termux — langsung dari HP Android kamu.

Apa Itu Curl?

curl adalah utilitas yang bisa ngirim dan terima data lewat berbagai protokol: HTTP, HTTPS, FTP, dan lainnya. Buat apa? Testing API, download file, submit form, scrape data — semua bisa dari terminal tanpa browser.

Install Curl di Termux

Kebanyakan versi Termux udah include curl. Tapi kalau belum, install gampang:

pkg update && pkg install curl

Selesai. Cek versi dengan curl --version.

Perintah Dasar Curl

1. GET Request — Ambil Data

Buat ambil data dari API atau website:

curl https://api.example.com/data

Output akan muncul di terminal. Tambahkan -i buat lihat header response juga.

2. POST Request — Kirim Data

Buat submit form atau kirim data ke API:

curl -X POST https://api.example.com/login \
  -H "Content-Type: application/json" \
  -d '{"username":"asmady","password":"rahasia"}'

-X POST set method, -H tambah header, -d kirim data body.

3. Download File

Download file langsung dari terminal:

curl -O https://example.com/file.zip

-O simpan dengan nama asli file. Atau pakai -o namafile.zip buat nama custom.

4. Follow Redirect

Kalau URL redirect ke tempat lain, tambahkan -L:

curl -L https://short.url/abc

curl akan ikuti redirect sampai dapat tujuan akhir.

5. Save Output ke File

Alih-alih tampil di terminal, simpan langsung ke file:

curl https://api.example.com/data.json -o data.json

Berguna buat nyimpen response API buat diproses lagi.

Tips dan Trik

  • -s mode silent — nggak tampil progress bar
  • -v verbose — lihat detail request/response, berguna buat debug
  • -k skip SSL verification — hati-hati, cuma buat testing
  • --max-time 30 set timeout 30 detik

Kesalahan Umum

Paling sering: lupa escape karakter khusus di JSON. Kalau dapat error "unexpected character", cek lagi JSON body-nya. Kedua: lupa tambah header Content-Type saat POST data. Banyak API yang reject kalau header ini nggak ada.

Kesimpulan

curl adalah tools yang wajib dikuasai siapa aja yang berhubungan dengan API atau otomasi. Di Termux, kamu bisa testing API, download file, dan bikin script otomasi langsung dari HP. Mulai dari perintah dasar, terus explore — curl itu dalam dan powerful.
